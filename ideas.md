# Дизайн-концепции для Дашборда Выездов

## Концепция 1: Минималистичный Неоморфизм
**Вероятность: 0.08**

**Дизайн-движение:** Неоморфизм с мягкими тенями и приглушённой палитрой

**Основные принципы:**
- Мягкие, едва заметные тени вместо чётких границ
- Монохромная палитра с одним акцентным цветом (серо-голубой)
- Плавные переходы между элементами
- Минимум визуального шума

**Философия цвета:**
Нейтральная база (светло-серый фон) с мягкими серо-голубыми окнами. Акцентный цвет - глубокий синий для выделения активных элементов. Цель - создать спокойную, сосредоточенную атмосферу.

**Парадигма макета:**
Сетка 3×4 с равномерным расстоянием между окнами. Каждое окно - плавающий элемент с мягкой тенью. Заголовок дашборда вверху с минимальным оформлением.

**Сигнатурные элементы:**
- Мягкие скруглённые углы (radius: 16px)
- Приглушённые тени (0 8px 24px rgba(0,0,0,0.08))
- Микро-анимации при наведении (lift-up эффект)

**Философия взаимодействия:**
Окна слегка поднимаются при наведении, показывая глубину. При клике - небольшой пульс. Плавные переходы всех состояний.

**Анимация:**
- Entrance: Fade-in + scale-up (0.3s ease-out)
- Hover: Transform translateY(-4px) + shadow increase (0.2s ease-out)
- Click: Brief scale pulse (0.15s)

**Типографическая система:**
- Display: Poppins Bold 32px (заголовок дашборда)
- Title: Poppins SemiBold 18px (название выезда)
- Body: Inter Regular 14px (дата)
- Accent: Poppins Bold 36px (количество участников)

## Концепция 2: Ретро-Компьютерный Стиль (Windows 95)
**Вероятность: 0.07**

**Дизайн-движение:** Ностальгический интерфейс операционной системы 90-х

**Основные принципы:**
- Классические 3D beveled borders (приподнятые края)
- Серая палитра с синими акцентами
- Пиксельная точность и чёткие границы
- Классические элементы управления (title bar, minimize/maximize buttons)

**Философия цвета:**
Серый фон (системный цвет), белые окна с серыми заголовками. Синие кнопки и акценты. Цель - вызвать ностальгию и создать узнаваемый интерфейс.

**Парадигма макета:**
Окна расположены в каскадном порядке или сетке, каждое с классическим title bar. Возможность "перемещения" окон (визуально, не функционально). Системный трей внизу.

**Сигнатурные элементы:**
- Beveled borders (светлые сверху/слева, тёмные снизу/справа)
- Классические кнопки (minimize, maximize, close)
- Пиксельные иконки
- Системный шрифт (MS Sans Serif или аналог)

**Философия взаимодействия:**
Клики издают звуки (опционально). Окна можно "развернуть" для получения большей информации. Наведение на кнопки показывает 3D эффект.

**Анимация:**
- Entrance: Slide-in + fade (0.4s)
- Hover: 3D button press effect (0.1s)
- Window expand: Smooth resize (0.3s)

**Типографическая система:**
- Display: MS Sans Serif Bold 16px (title bar)
- Title: MS Sans Serif 14px (название выезда)
- Body: MS Sans Serif 12px (дата)
- Accent: MS Sans Serif Bold 24px (количество участников)

## Концепция 3: Современный Glassmorphism с Градиентами
**Вероятность: 0.06**

**Дизайн-движение:** Современный glassmorphism с размытыми фонами и яркими градиентами

**Основные принципы:**
- Полупрозрачные окна с эффектом размытия (backdrop-filter: blur)
- Яркие градиентные акценты (от фиолетового к розовому)
- Динамические цветовые переходы
- Слоистая композиция с глубиной

**Философия цвета:**
Тёмный фон (почти чёрный) с размытым градиентом позади. Окна - полупрозрачные с белым текстом. Акцентные градиенты: фиолетовый → розовый → оранжевый. Цель - создать современный, энергичный вид.

**Парадигма макета:**
Сетка 2×6 или 3×4 с окнами, расположенными с небольшим смещением (offset grid). Каждое окно имеет уникальный градиентный акцент. Фоновые элементы - абстрактные размытые формы.

**Сигнатурные элементы:**
- Glassmorphic cards (backdrop-filter: blur(10px))
- Градиентные borders или accents
- Размытые фоновые элементы
- Неоновые акценты

**Философия взаимодействия:**
Окна светятся при наведении, показывая свой градиент ярче. Клик вызывает волновой эффект. Плавные, жидкие анимации.

**Анимация:**
- Entrance: Blur-in + fade (0.5s ease-out)
- Hover: Glow effect + gradient shift (0.3s ease-out)
- Click: Ripple effect (0.4s ease-out)

**Типографическая система:**
- Display: Outfit Bold 36px (заголовок дашборда)
- Title: Outfit SemiBold 20px (название выезда)
- Body: Inter Regular 14px (дата)
- Accent: Outfit Bold 40px (количество участников)

## Выбранная концепция: **Минималистичный Неоморфизм**

Я выбираю **Концепцию 1** как основу для дизайна. Эта концепция предоставляет:
- **Спокойную, профессиональную атмосферу** - идеально для дашборда
- **Мягкие, приятные для глаз элементы** - удобно для длительного просмотра
- **Современный, но не чрезмерный вид** - не отвлекает от данных
- **Отличную читаемость** - информация о выездах четко видна

Дизайн будет использовать:
- Светлый фон (почти белый)
- Мягкие серо-голубые окна с едва заметными тенями
- Глубокий синий цвет для акцентов
- Шрифты Poppins (заголовки) и Inter (основной текст)
- Плавные микро-анимации при взаимодействии
