# 🚀 Дашборд выездов 2026

Интерактивный дашборд для управления информацией о выездах с интеграцией Google Drive, красивым интерфейсом и автоматической синхронизацией данных.

## ✨ Возможности

- 📊 **Красивый дашборд** - Liquid Glass дизайн с полупрозрачными карточками
- 🔄 **Синхронизация с Google Drive** - Автоматическое обновление данных каждые 4 часа
- 👥 **Управление участниками** - Просмотр списка участников с статусом оплаты
- 📅 **Календарь выездов** - Визуальное отображение месяцев с выездами
- 💾 **Кэширование** - Быстрая загрузка данных из БД
- 🌐 **Адаптивный дизайн** - Работает на мобильных, планшетах и десктопах
- 🔐 **OAuth аутентификация** - Безопасная авторизация через Manus
- 📱 **Русский язык** - Полностью локализованный интерфейс

## 🛠 Технологический стек

### Frontend
- **React 19** - UI библиотека
- **TypeScript** - Типизированный JavaScript
- **Tailwind CSS 4** - Утилиты для стилизации
- **Vite** - Быстрый сборщик

### Backend
- **Node.js** - Runtime

### Database
- **MySQL** - Реляционная БД
- **Drizzle ORM** - Type-safe ORM

### Интеграции
- **Google Drive API** - Загрузка данных о выездах
- **Manus OAuth** - Аутентификация
- **Manus Analytics** - Отслеживание посещений

## 🚀 Быстрый старт

### Локальная разработка

#### Требования
- Node.js 22+
- pnpm 10+
- MySQL 8.0+

#### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/kubiklibrika/trips-dashboard.git
cd trips-dashboard

# Установите зависимости
pnpm install

# Создайте .env файл
cp .env.example .env

# Отредактируйте .env и установите необходимые переменные
# (см. DOCKER_SETUP.md для полного списка переменных)

# Запустите миграции БД
pnpm db:push

# Запустите dev сервер
pnpm dev
```

Приложение будет доступно по адресу `http://localhost:3000`

### Docker

Для развертывания с помощью Docker см. [DOCKER_SETUP.md](./DOCKER_SETUP.md)

```bash
# Быстрый старт с Docker
git clone https://github.com/kubiklibrika/trips-dashboard.git
cd trips-dashboard
cp .env.example .env
# Отредактируйте .env файл
docker-compose up -d
```

Приложение будет доступно по адресу `http://localhost:3000`

## 📊 Функциональность

### Главная страница
- Статистика (всего выездов, участников, среднее на выезд)
- Сетка карточек выездов с информацией
- Кнопка обновления для ручной синхронизации
- Календарь с выездами по месяцам

### Карточка выезда
- Название выезда
- Дата проведения
- Количество участников (цветовое кодирование)
- Статистика по оплате (оплачено/не оплачено)
- Клик для просмотра списка участников

### Модальное окно участников
- Полный список участников
- Статус оплаты для каждого
- Информация о выезде (название, дата)

### Синхронизация данных
- Автоматическое обновление каждые 4 часа
- Кэширование на сервере (TTL 10 минут)
- Ручное обновление через кнопку

## 🔐 Переменные окружения

Основные переменные (см. полный список в `.env.example`):

```env
# Database
DATABASE_URL=mysql://user:password@localhost:3306/trips_dashboard

# OAuth
VITE_APP_ID=your_app_id
OAUTH_SERVER_URL=https://api.manus.im
JWT_SECRET=your_secret

# Google Drive
GOOGLE_DRIVE_CREDENTIALS={"type":"service_account",...}

# App
VITE_APP_TITLE=Дашборд выездов
APP_URL=http://localhost:3000
```

## 🐛 Решение проблем

### Ошибка подключения к БД
- Проверьте переменную `DATABASE_URL`
- Убедитесь, что MySQL запущен
- Проверьте права доступа

### Данные не синхронизируются
- Проверьте `GOOGLE_DRIVE_CREDENTIALS`
- Убедитесь, что Google Drive API включен
- Проверьте логи: `docker-compose logs app`

### Фронтенд не загружается
- Очистите кэш браузера
- Перезагрузите страницу
- Проверьте консоль браузера на ошибки
